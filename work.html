Production Client Website Education / Preschool Bilingual UI (EN / NP)

Aama Pathshala — Bilingual Educational Platform

A bilingual website for a preschool in Nepal, designed specifically to convert parental inquiries into enrollments rather than just act as a static digital brochure.

The Original Problem

A preschool website has one crucial job: give parents immediate peace of mind regarding child safety, transport reliability, and educational care, and make submitting an admission enquiry effortless. Most local school websites fail because they bury crucial facility facts under dense, English-only walls of text that load slowly on mobile data.

What Was Built

A responsive, mobile-first website where admission forms and contact points sit prominently in the first screen. Rather than vague adjectives, amenities are stated as concrete numbers (class sizes, air-conditioned rooms, school bus routes, safety CCTV). The entire interface switches seamlessly between English and Nepali.

Key Implementation Decisions

  • Zero Framework Overhead: Built using vanilla semantic HTML5, modern CSS3, and vanilla JavaScript. Eliminating heavy client-side libraries kept the bundle size tiny and ensured sub-second loading on local 3G mobile devices.
  • Lightweight Bilingual Toggle: Implemented a clean DOM data-attribute language switcher that remembers the user's preferred language across visits without triggering full page reloads.
  • Direct Communication Links: Integrated WhatsApp, telephone, and location directions directly into sticky mobile action buttons for frictionless parent access.

Production Infrastructure Systems & Deployment Linux / Ubuntu / Caddy

Production Server Hardening & Automated Deployment Pipeline

Standardized cloud VPS architecture that replaces insecure default configurations and manual FTP transfers with automated, zero-downtime deployment pipelines.

The Original Problem

Businesses relying on shared hosting face frequent resource throttling, unpredictable downtime, and outdated PHP runtimes. When moving to dedicated cloud VPS instances (e.g. DigitalOcean, Linode, Hetzner), servers are frequently left in default configurations with root password authentication exposed to SSH brute-force bots and unencrypted traffic.

What Was Built

A repeatable production infrastructure blueprint deployed on Ubuntu LTS Linux: - Enforced Ed25519 SSH key authentication with password logins disabled. - Uncomplicated Firewall (UFW) restricting incoming traffic to only HTTP, HTTPS, and non-default SSH. - Reverse proxy with modern HTTP/3 and automated Let's Encrypt certificate renewal. - GitHub Actions automated deployment workflow triggering on main branch merges.

Key Implementation Decisions

  • Caddy over Traditional Nginx: We selected Caddy for production edge routing because of its out-of-the-box automatic TLS certificate management, eliminating expired certificate panics.
  • Security Headers by Default: Every site served includes HSTS, nosniff, and frame restriction headers to guard against clickjacking and MIME attacks.
  • Atomic GitHub Actions Deployments: Replaced manual FTP file uploads with Git-based deployment actions to guarantee that files are never deployed partially or corrupted mid-transfer.
Environment Ubuntu Linux LTS, Cloud VPS
Routing & TLS Caddy / Nginx, Let's Encrypt, HTTP/3
CI/CD Pipeline GitHub Actions, Automated Dispatch

AayushAI Core — Offline-First Terminal Assistant with Persistent Memory

A developer terminal assistant that runs entirely locally, solving session context amnesia by backing long-term memories with a structured SQLite database.

The Original Problem

Cloud-based chat assistants suffer from amnesia: close the browser tab or terminal session, and the context of your ongoing projects disappears, forcing you to re-explain background details repeatedly. Furthermore, syncing sensitive local developer notes to third-party cloud platforms poses privacy concerns.

What Was Built

A Python-based command-line tool designed for local execution. Long-term memory is implemented as a relational SQLite database rather than an ephemeral context window. Reminders, developer notes, and project journal entries are first-class structured tables that carry across terminal reboots and remain instantly searchable.

Key Implementation Decisions

  • Relational Memory vs Prompt Stuffing: By treating memory as database rows, queries can selectively fetch relevant context rather than saturating token windows.
  • Local Data Sovereignty: All data resides on the user's local disk in standard SQLite format, inspectable and exportable at any time.
  • Text-to-Speech Output: Integrated local speech synthesis allows hands-free query responses while working in editor environments.
