Service Offerings & Scopes

Defined capabilities, itemized deliverables.

Every Yugya engagement is structured around an explicit operational requirement, a concrete deliverable, and documented handover.

Below is a breakdown of what we build, who it is for, what the deliverable includes, and what happens once the project is shipped.

SERVICE 01

Website & Web Application Development

Available Offering

What it is & Who needs it

Custom web development for businesses, schools, and organizations that need a clear digital front door or interactive web tool. Suited for teams needing a website that is straightforward to navigate, loads reliably on mobile screens, and does not require complex proprietary hosting.

The Problem it solves

Many websites become bloated with unnecessary third-party plugins, scripts, and heavy frameworks that slow down browsing and make future edits difficult. We build clean, lightweight sites that prioritize readability, fast loading, and direct contact options.

What the deliverable includes

  • Semantic HTML5, CSS3, and JavaScript codebase without unnecessary dependencies
  • Responsive layouts tested across mobile, tablet, laptop, and desktop viewports
  • Bilingual architecture support (e.g. English + Nepali toggles) where required
  • Accessible structure: logical heading hierarchy, form labels, and visible keyboard focus states
  • Technical metadata setup: canonical URLs, OpenGraph tags, and Schema.org JSON-LD
  • Complete Git repository and asset files handed over to your team

What happens after delivery?

We assist with deployment to your production server or static hosting platform, provide a written guide on how to update content, and include 30 calendar days of bug fixing support.

SERVICE 02

Linux Server Setup, VPS & Deployment Pipelines

Available Offering

What it is & Who needs it

Configuring and securing Linux virtual private servers (VPS) on cloud providers such as DigitalOcean, Linode, Hetzner, or AWS. Ideal for teams moving away from shared hosting who need dedicated resources, stability, and control.

The Problem it solves

Default cloud server installations typically leave root password authentication enabled and firewalls disabled. We set up a documented, secure Linux environment with proper access controls and automated deployment hooks.

What the deliverable includes

  • OS provisioning (Ubuntu LTS or Debian) with dedicated non-root user and SSH key authentication
  • UFW firewall configuration and Fail2ban intrusion prevention rules
  • Reverse proxy (Caddy or Nginx) with automated Let's Encrypt TLS/SSL certificates
  • Automated deployment pipeline using Git hooks or GitHub Actions CI/CD
  • Systemd service configuration for automated process management and crash restarts
  • Documented server runbook and backup routine instructions

What happens after delivery?

All SSH keys, server passwords, and cloud dashboard accesses remain under your direct control. We deliver a Markdown runbook explaining how to restart services, view system logs, and inspect status.

SERVICE 03

Domain Guidance & DNS Architecture

Available Offering

What it is & Who needs it

Assistance with preparing national ccTLD documentation (specifically Nepal's official .np domains), purchasing commercial domains (.com, .org), and setting up reliable DNS routing.

The Problem it solves

In Nepal, registering a free .com.np domain requires specific company registration paperwork and formal cover letters that are often delayed or rejected if formatted incorrectly. In addition, missing or misconfigured email records (SPF, DKIM, DMARC) cause legitimate emails to end up in spam.

What the deliverable includes

  • Official Nepal .np application paperwork audit and cover letter preparation
  • DNS routing configuration on Cloudflare or provider of choice with DNSSEC support
  • Email authentication records: MX, SPF, DKIM, and DMARC for Google Workspace, Zoho, or private mail
  • Subdomain mapping for web applications, staging environments, and APIs
  • Documentation of all active DNS records for future reference

What happens after delivery?

Your domain account remains in your legal ownership. We deliver an export of all configured DNS records and configuration steps so any developer can maintain them.

SERVICE 04

Business Automation & Custom Tooling

Scoped Engagement

What it is & Who needs it

Lightweight scripts, automated data processing routines, and utility tools written in Python or Node.js. For teams that spend time manually re-entering or copying data across spreadsheets, forms, or messaging channels.

The Problem it solves

Repetitive manual data entry is slow and prone to typographical errors. We write straightforward, well-documented scripts to automate these tasks with clear logging.

What the deliverable includes

  • Workflow discovery: documenting inputs, transformation rules, and output requirements
  • Standalone Python or Node.js script with error handling and logging
  • Local SQLite or CSV export pipeline for structured storage
  • Automated alert mechanism (webhook or email notification) upon error or completion
  • Clear instruction manual and cron schedule instructions for running the script

What happens after delivery?

We verify sample runs together with your team, demonstrate how error handling works, and document how to update parameters as business requirements change.

What happens after delivery?

At the end of each billing cycle, you receive a concise summary report outlining maintenance actions taken and system health status.
